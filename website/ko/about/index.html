CleanKoach 소개

CleanKoach는 독립 개발자 Ak가 만들고 운영하는 Android용 저장공간 정리 앱입니다. 소중한 사진과 동영상을 위험에 빠뜨리지 않고 공간을 되찾도록 도와 드립니다.

하는 일

  • 공간을 차지하는 것을 찾습니다: 큰 파일, 똑같은 중복, 비슷한 사진, 스크린샷.
  • 남기는 파일을 압축합니다: 사진 최적화와 동영상 최적화가 절약한 공간을 보여 줍니다.
  • 남은 찌꺼기를 치웁니다: 정리하기는 휴지통의 사진과 동영상, 앱 캐시를 한 번의 탭으로 삭제합니다.
  • 휴대폰을 지켜봅니다: 활동 모니터, Wi-Fi 보안, 네트워크 속도.

작동 방식

사진, 동영상, 오디오는 휴대폰 안에서 분석됩니다. 미디어, 사용 데이터, 검사 결과는 업로드되지 않으며 앱에는 계정이 없습니다. 무엇을 삭제할지는 직접 선택하고, 미디어를 삭제하기 전에 Android가 확인을 요청합니다. 자세한 내용은 개인정보처리방침을 읽어 보세요.

운영 방식

CleanKoach는 무료로 사용할 수 있습니다. 광고는 홈 화면과 작업 사이에 표시됩니다. Pro는 광고를 없애 줍니다.

언어
