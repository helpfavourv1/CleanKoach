Patakaran sa privacy

Huling na-update: Oktubre 12, 2026

Ang CleanKoach ay storage cleanup app para sa Android. Ipinapaliwanag ng patakarang ito kung anong datos ang ina-access ng app, ano ang ginagawa nito rito, at ano ang hindi nito kailanman ginagawa.

Datos na hindi namin kailanman kinokolekta

Hindi kinokolekta, ipinapadala o iniimbak ng app ang alinman sa mga sumusunod sa aming mga server o sa mga server ng iba:

  • Ang mga litrato, video o audio file mo
  • Ang mga resulta ng anumang scan
  • Ang iyong mga istatistika ng paggamit (anong mga app ang binuksan mo, kailan, o gaano katagal)
  • Ang pangalan ng Wi-Fi network mo, uri ng encryption o resulta ng security test
  • Anumang impormasyon ng account. Walang account ang CleanKoach.

Datos na pinoproseso sa device mo

Ang sumusunod na datos ay binabasa at pinoproseso nang buo sa device mo. Hindi ito kailanman lumalabas sa phone mo sa pamamagitan ng app na ito.

Mga litrato, video at audio

Sa pahintulot mo, binabasa ng app ang media library mo para maghanap ng malalaking file, duplicate, magkakahawig na litrato at screenshot. Sinusuri ang mga file sa device. Walang ina-upload.

Mga istatistika ng paggamit

Kung bibigyan mo ng Usage Access, binabasa ng app ang kasaysayan ng pagbukas ng mga app mo sa nakaraang 24 oras para patakbuhin ang Activity Monitor. Nananatili sa device mo ang datos na ito at hindi ina-upload o ibinabahagi.

Impormasyon ng Wi-Fi

Binabasa ng Wi-Fi Security feature ang uri ng encryption ng kasalukuyan mong koneksyon, tinitingnan kung may proxy na naka-set para rito, at bine-verify ang security certificate ng isang test website (www.google.com). Walang payload na ipinapadala maliban sa karaniwang handshake ng secure na koneksyon, at walang resultang ina-upload.

Network speed test

Dina-download ng Network Speed feature ang isang test file mula sa pampublikong speed-test server ng Cloudflare (speed.cloudflare.com) at sinusukat kung gaano kabilis itong dumating. Tulad ng anumang website, makikita ng server na iyon ang IP address mo. Walang ibang datos na ipinapadala ang CleanKoach at hindi nito iniimbak ang resulta kahit saan maliban sa screen mo.

Settings

Ang iyong mga kagustuhan (tema, wika, notification settings) ay nakaimbak lamang sa device mo.

Diagnostics

Kung mag-crash ang app, nagtatabi ito ng maikling ulat ng huling crash at ng mga kamakailang pangyayari sa app sa pribadong storage nito sa device mo. Walang ina-upload. Lalabas lang ang ulat sa phone mo kung bubuksan mo ang Settings, tapos Diagnostics, at ikaw mismo ang pipili ng Copy o Share.

Ang website na ito

Ang website na ito ay static site na naka-host sa Cloudflare. Wala itong account, komento o form. Ang site mismo ay hindi nagse-set ng cookies at sa ngayon ay hindi nagpapatakbo ng analytics o advertising. Tulad ng anumang website, natatanggap ng mga server ng Cloudflare ang IP address at detalye ng browser mo kapag nilo-load mo ang isang pahina, para maihatid ito at mapanatiling ligtas.

Kung magdagdag ng advertising sa website na ito, ihahatid ito ng Google AdSense. Gagamit na ang Google at ang mga partner nito ng cookies at katulad na teknolohiya para magpakita at sumukat ng mga ad, at ang mga bisita sa European Economic Area, United Kingdom at Switzerland ay hihingan muna ng pahintulot sa pamamagitan ng consent message ng Google. Ia-update ang patakarang ito bago lumabas ang anumang ad.

Advertising

Nagpapakita ang CleanKoach ng mga ad sa pamamagitan ng Google AdMob: isang maliit na banner sa ibaba ng home screen, ng settings screen at ng mga tool screen, at paminsan-minsang full-screen ad matapos mong tapusin ang isang aksyon tulad ng clean-up. Hindi kailanman lumalabas ang mga ad sa Pro purchase screen, habang may tumatakbong scan, o sa ibabaw ng dialog ng pahintulot o consent. Kapag may inihahatid na ad, maaaring kolektahin ng Google ang advertising ID mo at karaniwang datos ng pakikipag-ugnayan sa ad, ayon sa nakasaad sa patakaran sa privacy ng Google. Hindi naka-link ang datos na ito sa anumang account, dahil walang account ang app.

Kung mag-upgrade ka sa Pro, aalisin ang lahat ng ad at wala nang advertising ID na kokolektahin ang app mula sa sandaling iyon.

Sa European Economic Area at United Kingdom, hihingan ka ng pahintulot bago maghatid ng anumang ad, sa pamamagitan ng User Messaging Platform ng Google. Maaari mong baguhin ang pasya mo anumang oras sa Privacy options ng app.

Mga pagbili at rating

Ang isang beses na pagbili ng Pro ay ganap na pinoproseso ng Google Play. Hindi kailanman nakikita ng CleanKoach ang detalye ng bayad mo; nalalaman lang nito mula sa Google Play kung aktibo ang Pro. Pagkatapos mong makatapos ng ilang clean-up, maaaring hilingin ng app sa Google Play na ipakita ang rating prompt nito. Ang ilalagay mo roon ay hawak ng Google, hindi ng CleanKoach.

Mga serbisyo ng third-party

  • Google AdMob at Google User Messaging Platform — mga ad at consent, ayon sa nakasaad sa itaas.
  • Google Play Billing at Google Play In-App Review — mga pagbili at rating prompt.
  • Cloudflare — nagho-host ng speed-test file at ng website na ito.

Mga pahintulot

  • Access sa litrato, video at audio — nag-i-scan at naglilinis ng media library mo.
  • Media management — opsyonal, Android 12 pataas. Hinahayaan ang CleanKoach na i-delete ang mga litrato, video at audio na pipiliin mo nang hindi humihingi ng kumpirmasyon ang Android sa bawat pagkakataon. Maaari mo itong i-off anumang oras sa Android Settings.
  • Usage Access — para lang sa Activity Monitor. Opsyonal.
  • Notifications — nagpapadala ng lingguhang paalala sa paglilinis at storage alert, kung i-e-enable mo.
  • Internet — naglo-load ng mga ad, nagsusuri ng mga pagbili at nagpapatakbo ng Wi-Fi at network speed test.
  • Network state — binabasa kung may internet access ka at anong uri ng Wi-Fi ang gamit mo.
  • Run at startup — ibinabalik ang iskedyul ng mga paalala mo pagkatapos mag-restart ang phone.

Mga bata

Hindi para sa mga batang wala pang 18 taong gulang ang CleanKoach. Hindi nito sinasadyang mangolekta ng anumang datos mula sa mga bata.

Ang iyong mga karapatan

Dahil hindi nangongolekta o nagpapadala ng personal na datos mula sa device mo ang CleanKoach, wala kaming ide-delete, ie-export o itatama para sa iyo. Ang datos na kinokolekta ng Google kapag may inihahatid na ad ay sakop ng patakaran sa privacy ng Google at ng mga pagpiling nasa Privacy options ng app. Kung gusto mong i-reset ang lokal na estado ng app, aalisin ng pag-uninstall ng app ang lahat.
