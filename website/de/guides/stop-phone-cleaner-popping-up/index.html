So stoppen Sie Handy-Cleaner-Pop-ups

Aktualisiert: 2026-10-12 · Von Ak

Kurzantwort

Um Handy-Cleaner-Pop-ups zu stoppen, finden Sie heraus, was sie anzeigt, und schalten Sie das ab. Die Ursache ist meist eine Website mit erlaubten Benachrichtigungen, eine App mit der Erlaubnis, über anderen Apps einzublenden, oder die eigenen Hinweise einer Cleaner-App. Halten Sie das Pop-up gedrückt, um zu sehen, welche App es gesendet hat, und blockieren oder deinstallieren Sie sie dann.

Ein Pop-up, das sagt, Ihr Handy müsse bereinigt werden, stammt nicht immer von einem Cleaner, den Sie installiert haben. Gehen Sie die folgenden Quellen durch, von der wahrscheinlichsten zur unwahrscheinlichsten.

Woher das Pop-up kommt

  • Eine Website: Sie haben Benachrichtigungen einer Seite in Ihrem Browser erlaubt, und sie sendet jetzt Hinweise.
  • Benachrichtigungen einer App: eine installierte App sendet Hinweise, die wie Systemwarnungen aussehen.
  • Eine App, die über anderen einblendet: eine App mit der Erlaubnis, über anderen Apps anzuzeigen.
  • Eine Seite in Ihrem Browser: eine gefälschte Warnung auf einer Webseite, die verschwindet, wenn Sie den Tab schließen.

Herausfinden, welche App oder Seite es ist

  1. Halten Sie die Benachrichtigung gedrückt. Android zeigt den Namen der App oder Seite.
  2. Prüfen Sie, wo sie erscheint. Im Benachrichtigungsbereich ist es eine Benachrichtigung. Über einer anderen App ist es ein Overlay. Innerhalb einer Webseite ist es die Seite.
  3. Notieren Sie den Namen und nutzen Sie dann die Tabelle unten.

Sind Cleaner-Apps sicher?

Website-Benachrichtigungen in Chrome blockieren

Öffnen Sie Chrome, dann Einstellungen, dann Websiteeinstellungen, dann Benachrichtigungen. Verschieben Sie jede Seite, der Sie nicht trauen, in die Liste der blockierten Seiten, oder schalten Sie Benachrichtigungen ganz aus. Chrome kann außerdem dezentere Hinweise nutzen, sodass Seiten ohne Pop-up anfragen können.

Mit Google Play Protect prüfen

Öffnen Sie den Play Store, tippen Sie auf Ihr Profilsymbol, tippen Sie auf Play Protect und starten Sie einen Scan. Achten Sie darauf, dass Apps mit Play Protect scannen eingeschaltet ist. Es prüft Apps auf schädliches Verhalten und kann Sie warnen oder sie entfernen.

Und CleanKoach?

CleanKoach zeigt keine Pop-ups über anderen Apps und fragt auch keine Erlaubnis dafür an. Die einzigen Benachrichtigungen sind eine wöchentliche Bereinigungserinnerung und Speicherhinweise, und beide sind aus, bis Sie sie einschalten. Um sie auszuschalten, öffnen Sie CleanKoach, dann Einstellungen, und schalten Sie die Benachrichtigungsoptionen aus, oder nutzen Sie die Benachrichtigungseinstellungen von Android für die App.

Häufige Fragen

Warum poppt ein Handy-Cleaner immer wieder auf?

Meist eine Website, für die Sie Benachrichtigungen erlaubt haben, eine App mit der Erlaubnis, über anderen Apps anzuzeigen, oder eine Cleaner-App, die Hinweise sendet.

Wie finde ich heraus, welche App das Pop-up anzeigt?

Halten Sie die Benachrichtigung gedrückt. Android zeigt die App oder Seite, die sie gesendet hat.

Wie stoppe ich Website-Benachrichtigungen auf Android?

Öffnen Sie in Chrome Einstellungen, Websiteeinstellungen, Benachrichtigungen und blockieren Sie die Seite. Andere Browser haben eine ähnliche Einstellung.

Was ist Über anderen Apps einblenden?

Eine Android-Berechtigung, mit der eine App über anderen Apps zeichnen darf. Schalten Sie sie für jede App aus, die sie nicht braucht.

Ist ein Pop-up echt, das sagt, mein Handy habe einen Virus?

Fast nie, wenn es von einer Webseite oder einer unbekannten App kommt. Schließen Sie den Tab und tippen Sie es nicht an. Starten Sie einen Play-Protect-Scan, wenn Sie unsicher sind.

Poppt CleanKoach auf meinem Bildschirm auf?

Nein. CleanKoach blendet nicht über anderen Apps ein. Die wöchentliche Erinnerung und die Speicherhinweise sind optional und aus, bis Sie sie einschalten.

Wie schalte ich die CleanKoach-Erinnerungen aus?

Öffnen Sie CleanKoach, gehen Sie zu den Einstellungen und schalten Sie die Benachrichtigungsoptionen aus, oder nutzen Sie die Benachrichtigungseinstellungen von Android für die App.

Was, wenn das Pop-up nach dem Deinstallieren der App zurückkehrt?

Eine andere App oder eine Seite, die Sie weiterhin erlauben, sendet es. Wiederholen Sie die Schritte und starten Sie einen Play-Protect-Scan.

Sollte ich einen weiteren Cleaner installieren, um Pop-ups zu stoppen?

Nein. Entfernen Sie stattdessen die Quelle. Eine weitere App ist eine weitere Sache, die Hinweise anzeigen kann.
