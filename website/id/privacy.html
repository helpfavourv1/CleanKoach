Kebijakan privasi

Terakhir diperbarui: 12 Oktober 2026

CleanKoach adalah aplikasi pembersih penyimpanan untuk Android. Kebijakan ini menjelaskan data apa yang diakses aplikasi, apa yang dilakukannya dengan data itu, dan apa yang tidak pernah dilakukannya.

Data yang tidak pernah kami kumpulkan

Aplikasi tidak mengumpulkan, mengirimkan, atau menyimpan hal-hal berikut di server kami maupun server pihak lain:

  • Foto, video, atau file audio Anda
  • Hasil pemindaian apa pun
  • Statistik penggunaan Anda (aplikasi mana yang Anda buka, kapan, atau berapa lama)
  • Nama jaringan Wi-Fi, jenis enkripsi, atau hasil uji keamanan Anda
  • Informasi akun apa pun. CleanKoach tidak memiliki akun.

Data yang diproses di perangkat Anda

Data berikut dibaca dan diproses sepenuhnya di perangkat Anda. Data ini tidak pernah meninggalkan ponsel Anda melalui aplikasi ini.

Foto, video, dan audio

Dengan izin Anda, aplikasi membaca pustaka media Anda untuk menemukan file besar, duplikat, foto serupa, dan tangkapan layar. File dianalisis di perangkat. Tidak ada yang diunggah.

Statistik penggunaan

Jika Anda memberikan Akses Penggunaan, aplikasi membaca riwayat pembukaan aplikasi Anda selama 24 jam terakhir untuk menjalankan Monitor Aktivitas. Data ini tetap di perangkat Anda dan tidak diunggah atau dibagikan.

Informasi Wi-Fi

Fitur Keamanan Wi-Fi membaca jenis enkripsi koneksi Anda saat ini, memeriksa apakah proxy diatur untuknya, dan memverifikasi sertifikat keamanan situs uji (www.google.com). Tidak ada muatan yang dikirim selain jabat tangan koneksi aman standar, dan tidak ada hasil yang diunggah.

Uji kecepatan jaringan

Fitur Kecepatan Jaringan mengunduh file uji dari server uji kecepatan publik Cloudflare (speed.cloudflare.com) dan mengukur seberapa cepat file itu tiba. Seperti situs web mana pun, server tersebut dapat melihat alamat IP Anda. CleanKoach tidak mengirim data lain dan tidak menyimpan hasilnya di mana pun selain di layar Anda.

Pengaturan

Preferensi Anda (tema, bahasa, pengaturan notifikasi) hanya disimpan di perangkat Anda.

Diagnostik

Jika aplikasi mogok, aplikasi menyimpan laporan singkat tentang kemogokan terakhir dan peristiwa aplikasi terbaru di penyimpanan privatnya di perangkat Anda. Tidak ada yang diunggah. Laporan hanya keluar dari ponsel Anda jika Anda membuka Pengaturan, lalu Diagnostik, dan memilih Salin atau Bagikan sendiri.

Situs web ini

Situs web ini adalah situs statis yang dihosting di Cloudflare. Tidak ada akun, komentar, atau formulir. Situs ini sendiri tidak menyetel cookie dan saat ini tidak menjalankan analitik maupun iklan. Seperti situs web mana pun, server Cloudflare menerima alamat IP dan detail peramban Anda saat Anda memuat halaman, agar halaman dapat dikirim dan tetap aman.

Jika iklan ditambahkan ke situs web ini, iklan akan ditayangkan oleh Google AdSense. Google dan mitranya kemudian menggunakan cookie dan teknologi serupa untuk menampilkan dan mengukur iklan, dan pengunjung di Wilayah Ekonomi Eropa, Inggris Raya, dan Swiss akan lebih dulu diminta persetujuan melalui pesan persetujuan Google. Kebijakan ini akan diperbarui sebelum iklan apa pun muncul.

Iklan

CleanKoach menampilkan iklan melalui Google AdMob: spanduk kecil di bagian bawah layar utama, layar pengaturan, dan layar alat, serta sesekali iklan layar penuh setelah Anda menyelesaikan tindakan seperti pembersihan. Iklan tidak pernah muncul di layar pembelian Pro, saat pemindaian berjalan, atau di atas dialog izin atau persetujuan. Saat iklan ditayangkan, Google dapat mengumpulkan ID iklan Anda dan data interaksi iklan standar sebagaimana dijelaskan dalam kebijakan privasi Google. Data ini tidak terhubung ke akun mana pun, karena aplikasi tidak memiliki akun.

Jika Anda meningkatkan ke Pro, semua iklan dihapus dan aplikasi tidak lagi mengumpulkan ID iklan sejak saat itu.

Di Wilayah Ekonomi Eropa dan Inggris Raya, persetujuan Anda akan diminta sebelum iklan apa pun ditayangkan, melalui User Messaging Platform milik Google. Anda dapat mengubah pilihan kapan saja di Opsi privasi aplikasi.

Pembelian dan penilaian

Pembelian Pro satu kali diproses sepenuhnya oleh Google Play. CleanKoach tidak pernah melihat detail pembayaran Anda; aplikasi hanya mengetahui dari Google Play apakah Pro aktif. Setelah Anda menyelesaikan beberapa kali pembersihan, aplikasi dapat meminta Google Play menampilkan permintaan penilaian. Apa yang Anda masukkan di sana ditangani oleh Google, bukan CleanKoach.

Layanan pihak ketiga

  • Google AdMob dan Google User Messaging Platform — iklan dan persetujuan, seperti dijelaskan di atas.
  • Google Play Billing dan Google Play In-App Review — pembelian dan permintaan penilaian.
  • Cloudflare — menghosting file uji kecepatan dan situs web ini.

Izin

  • Akses foto, video, dan audio — memindai dan membersihkan pustaka media Anda.
  • Pengelolaan media — opsional, Android 12 ke atas. Memungkinkan CleanKoach menghapus foto, video, dan audio yang Anda pilih tanpa Android meminta konfirmasi setiap kali. Anda dapat mematikannya kapan saja di Pengaturan Android.
  • Akses Penggunaan — hanya untuk Monitor Aktivitas. Opsional.
  • Notifikasi — mengirim pengingat pembersihan mingguan dan peringatan penyimpanan, jika Anda mengaktifkannya.
  • Internet — memuat iklan, memeriksa pembelian, dan menjalankan uji Wi-Fi dan kecepatan jaringan.
  • Status jaringan — membaca apakah Anda memiliki akses internet dan jenis Wi-Fi yang Anda gunakan.
  • Jalankan saat startup — memulihkan jadwal pengingat Anda setelah ponsel dihidupkan ulang.

Anak-anak

CleanKoach tidak ditujukan untuk anak di bawah 18 tahun. Aplikasi ini tidak dengan sengaja mengumpulkan data apa pun dari anak-anak.

Hak Anda

Karena CleanKoach tidak mengumpulkan atau mengirimkan data pribadi dari perangkat Anda, tidak ada yang perlu kami hapus, ekspor, atau perbaiki atas nama Anda. Data yang dikumpulkan Google saat iklan ditayangkan diatur oleh kebijakan privasi Google dan pilihan di Opsi privasi aplikasi. Jika Anda ingin mengatur ulang status lokal aplikasi, menghapus instalan aplikasi akan menghapus semuanya.

Perubahan kebijakan ini

Jika kebijakan ini berubah, versi yang diperbarui akan muncul di URL ini dengan tanggal “Terakhir diperbarui” yang baru.
